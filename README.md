## Approved Idea: Age / Eligibility Gate
> *Prove a threshold without revealing the underlying value.*

This dApp proves that a user is at least 18 years old using a **Zero-Knowledge Proof** on the Midnight network. The user's exact age is **never** transmitted to any server, stored on any ledger, or visible to any observer — only a cryptographic proof that the condition `age ≥ 18` is satisfied is submitted to the blockchain.

---

## Privacy Model

### What an observer CAN learn
| Observable | Value |
|---|---|
| A contract deployment transaction occurred | ✅ Yes — visible on-chain |
| The minimum age threshold enforced | ✅ Yes — `18` is stored in the public ledger state |
| Whether verification succeeded | ✅ Yes — `lastVerificationSuccess: true` is public |
| The contract address | ✅ Yes — public |
| The wallet address that deployed | ✅ Yes — public |

### What an observer CANNOT learn
| Hidden | Why |
|---|---|
| The user's actual age | ❌ Never stored anywhere — kept entirely in the user's browser |
| Whether the user is 18, 25, or 99 | ❌ The ZK proof reveals only that `age ≥ 18` holds |
| Any biometric or identity data | ❌ No such data is ever collected |
| The exact numeric value passed to the circuit | ❌ The prover runs locally; inputs stay private |

### How it works (ZK proof flow)
1. User types their age locally in the browser — **it never leaves their device**
2. The Midnight ZK circuit (`age-verifier.compact`) runs a local proof: `assert(myAge >= 18)`
3. A **cryptographic proof** (not the age itself) is generated by the proof server
4. The proof is submitted to the Midnight blockchain — only the boolean result is stored
5. Any observer can verify the proof is valid, but **cannot reverse-engineer the input**

## Tests & CI/CD

This project includes **12 automated tests** covering:
- Wallet connection UI state
- Age input field rendering
- Button disabled/enabled states
- WalletContext default values
- ZK verification flow guards

**Run tests locally:**
```bash
cd frontend
npm run test
```

**CI/CD Pipeline** (`.github/workflows/ci.yml`) runs on every push to `main`:
1. ✅ TypeScript typecheck (`tsc --noEmit`)
2. ✅ Run all 12 tests (`vitest run`)
3. ✅ Build production bundle (`vite build`)
4. ✅ Upload build artifact to GitHub Actions

## Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/debdeepadutta/stellar_newmoon.git
   cd stellar_newmoon
   ```

2. **Start the Midnight proof server (Docker)**
   ```bash
   npm run proof-server:start
   ```

3. **Install and run the frontend**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Connect your wallet, enter your age, and click "Prove Age Anonymously"**
